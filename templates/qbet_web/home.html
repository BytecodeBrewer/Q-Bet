Pipeline

Different inputs, shared checks after calculation.

01

Prepare the data

Each engine gets the data and preparation steps it needs instead of forcing every strategy through the same input format.

02

Run the calculation

Engine calculations use explicit inputs and return a proposal that can be checked independently.

03

Check before action

Risk and liquidity are checked before either route. Controlled Execution adds an explicit approval step; Simulation does not.

Execution settings
